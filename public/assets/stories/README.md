# Story animations / 故事动画

`fox-apple.gif` is the primary Animation Q&A demo (~12s). Frame stills live in `fox-apple/`.

`fox-apple.gif` 是「动画提问」主演示（约 12 秒）；分帧在 `fox-apple/`。

Parents can register another local GIF/PNG in **Parent settings**. Prefer calm, short loops you may redistribute.

家长可在「家长设置」登记其它本地 GIF/PNG。请使用可再分发的短平静动画。
