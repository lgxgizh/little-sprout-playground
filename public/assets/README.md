# 示例素材

`fox-hero.png` 是为本项目生成的示例插画，用于演示页面布局。`questions/` 里的贴纸是为本项目生成的 demo 题目插画。贡献者添加媒体文件时，必须确认素材允许公开再分发，并在此文件中记录来源与许可证。

本仓库不接受从商业儿童应用、流媒体服务或未授权网站复制的动画、图片、音频与题目。

主演示动画为 `stories/fox-apple.gif`（约 12 秒）。听力词卡用 JPEG：新卡在 `flashcards/{theme}/`，兼容旧键仍在 `choices/`。不要用 PNG 做词卡。旧版 `media/shapes-hello.mp4` 已降级，不再作为主演示。
