# Local media / 本地视频

`shapes-hello.mp4` is an original, copyright-free placeholder clip (colored shapes and simple English labels) generated for this project. It is safe to keep in a public demo.

`shapes-hello.mp4` 是为本项目生成的原创占位短片（纯色形状与简单英文标签），不含第三方动画或商标，可用于公开演示。

## Replace or add clips / 替换与添加

1. Put short, calm MP4/WebM files in this folder (`public/assets/media/`).
2. Prefer 5–20 seconds, clear visuals, and redistribution rights you control.
3. In the app, open **Parent settings → 本地动画理解** and either:
   - enter a path such as `assets/media/your-clip.mp4`, or
   - pick a local file for this browser session.
4. Add one English picture question (prompt + answer + 2–3 choices). The child flow is: watch → spoken question → tap a picture card.

Do **not** commit commercial cartoons, streaming rips, trademarked characters, or any media you cannot redistribute.

请勿提交商业动画片、流媒体资源、商标角色，或任何无权再分发的素材。
